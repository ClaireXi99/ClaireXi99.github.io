hidai25/eval-view

eval-view

已合并

项目用途

AI Agent 回归测试工具，记录行为快照、工具调用和评分变化，并在 CI 中识别回归。

使用场景

  • 比较 Agent 升级前后的工具调用
  • 监控同一测试的评分趋势

遇到的问题

统计结果只有平均值、最小值和最大值。评分连续下降时，在跌破阈值前仍可能看起来正常。

解决方式

增加斜率、方向和显著性；按时间正序计算趋势，并兼容 Python 3.9。新增 26 个测试覆盖数据库与命令行输出。

EvolvingLMMs-Lab/lmms-eval

lmms-eval

已合并

项目用途

覆盖文本、图像、视频和音频任务的多模态模型评测框架。

使用场景

  • 使用 MMMU 评测图像推理
  • 使用 VideoMME 评测视频理解

遇到的问题

MMMU 开放题的候选答案列表被提前压成字符串，后续评分器会按字符迭代，导致正确答案被低估。

解决方式

评分时保留完整候选列表，只有生成提交文件时才取首个答案；增加 143 行回归测试覆盖开放题和选择题。

truera/trulens

TruLens

已合并

项目用途

LLM 应用和 Agent 的评测、追踪与实验分析工具。

使用场景

  • 评测 RAG 检索排序
  • 比较模型评分与人工标签

遇到的问题

NDCG 在标准答案少于检索结果时发生形状错误；Cohen's kappa 又会原地修改真实标签，污染之后的指标。

解决方式

按标准 DCG/IDCG 公式计算 NDCG，并在局部副本上二值化标签，避免修改对象状态。

UKGovernmentBEIS/inspect_ai

Inspect AI

已合并

项目用途

面向大语言模型的评测框架，用任务、求解器和评分器组织可复现评测。

使用场景

  • 运行模型能力或安全评测
  • 用自定义标签计算准确率和部分得分

遇到的问题

配置数值型正确、错误和部分正确标签时，函数先做数值直通，导致准确率可能大于 1 或出现负数。

解决方式

先匹配自定义标签，再处理普通数值；保留 NaN、无穷值和非标签数值的原有行为。

LightRAG

项目用途

结合图结构与向量检索的 RAG 框架，用于构建文档问答和知识检索系统。

使用场景

遇到的问题

解决方式
