# 音乐生成实验课

在线阅读：https://clairexi99.github.io/topics/music-generation/

四条任务：文字生成纯音乐、清唱配伴奏、歌词成歌、MIDI。围绕具体数据样本、清洗配对、训练 loss 与更新、推理、音频评测展开。

- `content/`：七页正文，修改后运行 `python3 build.py`。
- `assets/`：离线样式、交互、教学音频、图表与数值模型。
- `research/create_audio_lab.py`：重新生成教学 WAV 和科学图表。
- `requirements.txt`：重建所需 Python 包；直接浏览不需要安装。

笔记只保存在当前浏览器，可导出与导入；不会上传至 GitHub。由本地文件切换到在线站点时，请先从原地址导出 JSON，再在新地址导入。

所有音频均由程序合成，用于说明数据处理与评测，不是商业模型输出。训练按钮更新的是小型数值模型，没有在浏览器中运行真实音乐大模型。公开资料版本截至 2026-09-09，原始来源见来源页。
