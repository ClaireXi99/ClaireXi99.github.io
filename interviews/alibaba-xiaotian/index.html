JD 需要了解的知识点

VLMEvalKit / EvalScope / lmms-eval

需要了解：数据集适配、Prompt 模板、推理后端、结果解析、评分器、并行执行和报告汇总。

知识点总结：通用评测框架把模型、数据集和评分协议解耦，便于复现、横向比较和持续回归。

MMMU / MMBench / Video-MME

需要了解：各基准覆盖的能力、数据格式、题型、评分协议、视频时长和能力切片。

知识点总结：公开基准提供专业推理、细粒度视觉理解和长视频理解的基础坐标，业务黄金集承接真实场景验证。

VBench

需要了解：主体一致性、背景一致性、运动平滑、动态程度、画质、美学和文本一致等分维度指标。

知识点总结：VBench 将视频生成质量拆成独立维度，适合比较模型版本并定位具体能力变化。

人评协议与 Pairwise

需要了解：Rubric、正反锚点、盲评、随机顺序、重复样本、双标、IAA 和专家仲裁。

知识点总结：结构化人评把主观质量转成可执行标准，并通过一致性数据验证标注体系。

数据血缘与主动抽样

需要了解：来源、许可、处理版本、样本父子关系、置信度、不确定性采样和失败簇采样。

知识点总结：数据血缘保证可追溯，主动抽样把标注资源集中到高价值长尾和模型分歧样本。

常见问题

  1. 如何评测文生图？

    提示词拆解；主体/属性/关系/文字/风格；图像质量；安全；自动指标 + VLM Judge + 人评；切片报告。

  2. 如何评测文生视频？

    文本一致、主体/背景时序一致、运动合理、镜头、闪烁、画质、审美、安全；人评验证自动指标。

  3. 怎样设计标注规范？

    任务目标；维度定义；正反例和边界例；试标；分歧分析；一致率；专家升级；版本化。

  4. 自动打标怎样控制错误放大？

    置信度分层；金标校准；难例人工；亚组抽检；漂移检测；保留模型/Prompt/版本。

  5. 如何把 Bad Case 反哺训练数据？

    失败簇→能力标签→缺口统计→定向采样/合成→去重与质量控制→训练→固定回归。

  6. Benchmark 分数上升但业务变差怎么办？

    检查污染、数据分布、指标代理失效、切片差异和实现版本；以业务黄金集和人评复核。
