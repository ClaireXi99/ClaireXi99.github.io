JD 需要了解的知识点

FastAPI + Pydantic

需要了解：异步接口、依赖注入、请求/响应 schema、错误码、Webhook、鉴权和 OpenAPI 文档。

知识点总结：FastAPI 与 Pydantic 组成清晰的 Python 接口层，适合连接企业系统、模型服务和工作流。

LangGraph

需要了解：状态图、节点与边、checkpoint、持久执行、人工审批、恢复、重放和多 Agent 编排。

知识点总结：LangGraph 用显式状态管理长流程 Agent，使执行过程可观察、可恢复并支持人工参与。

Dify / n8n

需要了解：可视化工作流、模型与工具连接、变量传递、条件分支、Webhook、知识库和运营配置。

知识点总结：低代码工作流平台适合快速完成 PoC、客户演示和可配置的业务流程交付。

MCP 2026 规范

需要了解：Tools、Resources、Prompts、JSON Schema、能力协商、传输方式和 OAuth 授权。

知识点总结：MCP 用统一协议连接模型与外部能力，核心价值是标准接口、清晰 schema 和受控授权。

OpenTelemetry GenAI 语义约定

需要了解：Trace、span、attribute、模型调用、工具调用、时延、Token、成本和错误状态。

知识点总结：OpenTelemetry 将 Agent 与模型链路统一到标准化可观测体系，支持性能分析、问题定位和成本统计。

Ragas / LangSmith 评测

需要了解：评测数据集、检索质量、groundedness、回答质量、实验对比、回归和结果追踪。

知识点总结：评测平台把 RAG 与 Agent 的质量转化为可重复实验和可持续版本回归。

结合简历怎么说

RAG 与企业业务落地

简历证据

Agent/Workflow

简历证据

Kubernetes 深度有限

面试表达：主讲 Docker、环境配置和服务排障；K8s 只讲 Deployment/Service/ConfigMap/Secret/日志等基础。

可完成练习：把 Demo 容器化并写 docker-compose；有余力再部署到本地 kind/minikube，演示滚动更新和配置注入。

常见问题

  1. 怎样把模糊客户需求变成任务？

    目标/用户/现状；数据与权限；接口和环境；成功指标；非目标；风险；拆成可演示、可测试、可验收任务。

  2. RAG 效果差怎样排查？

    query→召回→重排→上下文→Prompt→模型→引用逐层 trace；固定样本；区分无知识、检索错、生成错。

  3. Agent 工具调用如何保证安全？

    最小权限；schema 校验；allowlist；幂等；审批；超时重试；审计；敏感数据脱敏；回滚。

  4. 如何避免客户定制变成独立分支？

    配置优先；adapter/connector；插件接口；feature flag；公共核心与项目层分离；回收共性能力。

  5. 接口联调失败怎么排查？

    请求 ID；DNS/TLS/网络；认证授权；schema；超时重试；服务日志；依赖状态；最小复现。

  6. PoC 如何定义验收？

    业务任务成功率、质量集、延迟/成本、权限、故障恢复、可操作性、范围外事项和签字标准。

建议反问

  • 怎样定义可接受定制，谁有权拒绝不可维护需求？
  • 股权、项目分红、试用期和现金薪资的具体规则是什么？
