JD 需要了解的知识点

Python + PyArrow / Parquet

需要了解：Schema、列式存储、分区、批量扫描、类型校验，以及媒体 URI 与结构化元数据的组织方式。

知识点总结：Parquet 适合保存大规模数据清单和质量字段；媒体文件保存在对象存储，通过稳定 ID、URI 和哈希关联。

Spark / PySpark

需要了解：DataFrame、分区、shuffle、join、聚合、数据倾斜、广播表和幂等分区写入。

知识点总结：Spark 是成熟的分布式批处理引擎，适合完成大规模清洗、去重、聚合和刷库。

Ray Data

需要了解：Dataset block、map_batches、ActorPool、CPU/GPU 资源配置和批推理流水线。

知识点总结：Ray Data 适合用 Python 串联多模态预处理与模型推理，并统一调度 CPU 和 GPU 算子。

NeMo Curator

需要了解：规则过滤、模型过滤、精确/模糊/语义去重、隐私识别和数据处理记录。

知识点总结：NeMo Curator 展示了多模态训练数据从读取、过滤、去重到质量筛选的完整工程框架。

FFmpeg / OpenCV / Librosa

需要了解：媒体探测、转码、抽帧、分辨率与 FPS、音频重采样、响度、静音、削波和声学特征。

知识点总结：这组工具覆盖视频、图像和音频的基础处理，是多模态数据流水线的算子层。

常见问题

  1. 批任务跑到 70% 失败，怎样恢复且避免重复写入？

    稳定 ID；分片；checkpoint；幂等 upsert；失败队列；重试上限；完成后对账。

  2. 如何给多模态样本设计统一元信息？

    公共字段 + modality-specific 字段；源 URI/哈希；许可和隐私；算子版本；质量分；父子样本关系。

  3. 怎样判断数据质量？

    schema/文件有效性、内容规则、统计分布、模型评分、去重、人工分层抽检、下游效果验证。

  4. Spark 数据倾斜如何排查？

    看 stage 和 task 时长；定位重 key；采样；salting、预聚合、广播 join、调整分区。

  5. Linux 上任务变慢怎样排查？

    先区分 CPU、内存、磁盘 I/O、网络；top/vm_stat、iostat、df/du、lsof、日志和最近变更。

  6. 需求不清楚怎样避免返工？

    样例输入输出；边界和错误策略；小样验收；冻结 schema/版本；批量前质量闸门。
